# Soy Tungurahua.org

Versión institucional y de divulgación de conocimiento de [Soy Tungurahua](https://soytungurahua.com).

## Propósito

Reunir investigaciones, fuentes, memoria oral y datos abiertos para comprender las transformaciones culturales, históricas y territoriales de la provincia de Tungurahua, Ecuador.

## Principios editoriales

- Fuentes visibles y trazables.
- Distinción entre historia documentada, memoria oral, leyenda e interpretación.
- Conocimiento abierto y participación plural.
- Reconocimiento de autorías, procedencias y condiciones de uso.

## Identidad

Soy Tungurahua.org comparte la identidad visual de soytungurahua.com y cumple una función complementaria: la versión `.com` invita a descubrir el territorio; la versión `.org` organiza y divulga conocimiento sobre él.

## Publicación

El sitio se publica automáticamente en GitHub Pages desde la rama `main` y utiliza el dominio `soytungurahua.org`.
